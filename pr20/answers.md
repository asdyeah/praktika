# Ответы на вопросы для самоконтроля (ПР20)

1. В чем преимущества использования Express.js по сравнению с чистым Node.js для создания серверов?
   Готовая маршрутизация, middleware, парсинг JSON и обработка ошибок — меньше кода, больше возможностей.

2. Что такое middleware в Express.js и каков порядок их выполнения?
   Функции (req, res, next), выполняются строго в порядке регистрации через app.use().

3. Как организовать модульную структуру роутеров?
   Вынести маршруты в отдельные файлы с express.Router() и подключить через app.use().

4. Какие методы роутинга поддерживает Express.js?
   app.get, app.post, app.put, app.delete, app.patch, app.all.

5. Как обрабатывать параметры URL и query-параметры?
   req.params для URL-параметров, req.query для query-строки.

6. В чем разница между app.use() и app.METHOD()?
   app.use() — для middleware (все методы), app.METHOD() — для конкретного метода.

7. Как организовать централизованную обработку ошибок?
   app.use((err, req, res, next) => { ... }) в конце файла.

8. Что такое router.param()?
   Middleware для обработки конкретного параметра маршрута (например, :id).
