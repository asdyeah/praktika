# Ответы на вопросы ПР20
1. Преимущества Express.js: маршрутизация, middleware, упрощение кода.
2. Middleware — функции с (req, res, next).
3. Модульные роутеры: express.Router().
4. Методы: app.get, app.post, app.put, app.delete.
5. req.params, req.query.
6. app.use() — для middleware, app.METHOD() — для конкретного метода.
7. app.use((err, req, res, next) => {...}) в конце.
8. router.param() — middleware для валидации параметров.
