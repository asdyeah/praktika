# Ответы на вопросы ПР17
1. Управляемые - состояние в React, неуправляемые - в DOM.
2. Управляемые для сложной валидации, неуправляемые для простых форм.
3. onChange, onSubmit.
4. Динамические имена полей (e.target.name).
5. Встроенная HTML5, собственная логика, библиотеки (Formik, React Hook Form).
6. e.preventDefault().
7. Передача состояния от дочернего к родительскому компоненту.
