# Ответы на вопросы для самоконтроля (ПР17)

1. В чем разница между управляемыми и неуправляемыми компонентами в формах React?
   В управляемых значение поля хранится в состоянии React (useState), в неуправляемых — в DOM (через useRef).

2. Когда следует использовать управляемые компоненты, а когда — неуправляемые?
   Управляемые — для сложной валидации и динамического изменения полей, неуправляемые — для простых форм с минимальной логикой.

3. Какие методы используются для обработки событий в формах React?
   onChange (при вводе), onSubmit (при отправке), onBlur (при потере фокуса).

4. Как обрабатывать несколько полей ввода с одним обработчиком?
   Использовать атрибут name у полей и в обработчике обращаться к e.target.name и e.target.value.

5. Какие подходы к валидации форм в React вы знаете?
   Встроенная HTML5-валидация, ручная валидация через useState, сторонние библиотеки (Formik, React Hook Form).

6. Как предотвратить стандартное поведение формы?
   Вызвать e.preventDefault() внутри обработчика onSubmit.

7. Что такое "поднятие состояния" (lifting state up)?
   Передача состояния из дочернего компонента в родительский для синхронизации данных между компонентами.
