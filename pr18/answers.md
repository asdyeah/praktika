# Ответы на вопросы для самоконтроля (ПР18)

1. В чем разница между Link и NavLink в React Router?
   NavLink автоматически добавляет класс active к ссылке, если её путь совпадает с текущим URL.

2. Как получить параметры из URL в компоненте?
   С помощью хука useParams().

3. Что такое программная навигация и как ее реализовать?
   Переход по страницам без клика по ссылке. Реализуется через хук useNavigate() (например, navigate('/path')).

4. Как передать данные между маршрутами?
   Через объект state в <Link state={...}> или navigate('/path', { state: {...} }), а получить — через useLocation().

5. Что делает компонент Routes?
   Оборачивает все маршруты и рендерит только тот, который совпал с текущим URL.

6. Как создать защищённый маршрут?
   Создать компонент-обёртку, который проверяет авторизацию и либо рендерит дочерний компонент, либо делает редирект через <Navigate to="/login" />.

7. В чем разница между useNavigate и redirect?
   useNavigate — хук для навигации внутри компонентов, redirect — функция для использования в загрузчиках данных (loaders) React Router.
