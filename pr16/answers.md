# Ответы на вопросы для самоконтроля (ПР16)

1. В чем преимущества использования Express.js по сравнению с чистым Node.js для создания серверов?
   Express предоставляет готовую маршрутизацию, middleware, обработку ошибок и парсинг тела запроса, что сокращает количество шаблонного кода.

2. Что такое middleware в Express.js и каков порядок их выполнения?
   Middleware — это функции с сигнатурой (req, res, next), которые выполняются последовательно в порядке их подключения через app.use().

3. Как организовать модульную структуру роутеров в Express приложении?
   Создать отдельные файлы с express.Router(), экспортировать их и подключить в главном файле через app.use('/path', router).

4. Какие методы роутинга поддерживает Express.js и для чего они используются?
   app.get, app.post, app.put, app.delete, app.patch, app.all — для обработки соответствующих HTTP-методов.

5. Как обрабатывать параметры URL и query-параметры в Express?
   Параметры URL — через req.params (например, :id), query-параметры — через req.query.

6. В чем разница между app.use() и app.METHOD()?
   app.use() подключает middleware для всех методов, app.METHOD() — только для конкретного HTTP-метода.

7. Как организовать централизованную обработку ошибок в Express приложении?
   Добавить middleware с четырьмя аргументами (err, req, res, next) в конец файла.

8. Что такое router.param() и для чего он используется?
   Middleware для валидации или предобработки параметра маршрута (например, проверка ID на число).
