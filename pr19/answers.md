# Ответы на вопросы для самоконтроля (ПР19)

1. Что такое Node.js?
   Среда выполнения JavaScript на стороне сервера на базе движка V8.

2. Как создать простой HTTP-сервер в Node.js?
   Использовать модуль http: http.createServer((req, res) => {}).listen(PORT).

3. Что такое req и res?
   req — объект входящего запроса (метод, URL, тело), res — объект ответа (заголовки, статус, данные).

4. Какие HTTP-методы вы знаете?
   GET, POST, PUT, PATCH, DELETE, OPTIONS.

5. Как получить URL и метод из запроса?
   req.url и req.method. URL можно разобрать через модуль url.

6. Что такое REST API?
   Архитектурный стиль, где ресурсы доступны по URL, а действия — через HTTP-методы.

7. Зачем нужны заголовки CORS?
   Чтобы разрешить браузеру запросы с другого домена (origin).
