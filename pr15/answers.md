# Ответы на вопросы ПР15

## 1. Функциональные vs классовые компоненты

Функциональные — проще, короче, используют hooks, без `this`. Классовые — с состоянием и жизненным циклом через методы. Сейчас рекомендуются функциональные с hooks.

## 2. Props и state

**Props** — входные данные от родителя, только для чтения. **State** — внутреннее состояние компонента, изменяется через `setState` или `useState`. Props передаются сверху вниз, state принадлежит компоненту.

## 3. Lifting state up

Когда несколько компонентов должны разделять состояние — поднимают его в общего родителя и передают через props. Используется при синхронизации форм, фильтров, выбранных элементов.

## 4. Методы жизненного цикла

- `componentDidMount` — после монтирования (запросы, подписки)
- `componentDidUpdate` — после обновления (реакция на изменение props/state)
- `componentWillUnmount` — перед удалением (очистка таймеров, слушателей)
- `shouldComponentUpdate` — оптимизация рендера
- `render` — возвращает JSX

## 5. useState и useEffect

`useState` — хранит состояние и функцию его изменения. `useEffect` — выполняет побочные эффекты: запросы, подписки, таймеры. Правила хуков: только на верхнем уровне, только внутри функциональных компонентов или других хуков.

## 6. Ключи (keys)

Уникальные идентификаторы для элементов списка. Помогают React определять, какие элементы изменились, добавились или удалились. Без ключей — медленный рендер и баги.

## 7. События в React

В React — синтетические события (SyntheticEvent). Обработчики в camelCase (`onClick`, `onChange`). `preventDefault` работает, но `return false` не работает.

## 8. Управляемые и неуправляемые компоненты

**Управляемые** — значение контролируется React (`value` + `onChange`). **Неуправляемые** — DOM управляет значением, доступ через `ref`. Управляемые удобнее для валидации.

## 9. Context

Позволяет передавать данные через дерево компонентов без пропсов на каждом уровне. Используется для темы, языка, авторизации. Создаётся через `createContext`, `Provider` и `useContext`.

## 10. Кастомные хуки

Функции, начинающиеся с `use`, которые используют другие хуки. Позволяют повторно использовать логику между компонентами. Примеры: `useLocalStorage`, `useFetch`, `useDebounce`.
